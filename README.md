        
        
    🌐 Personal Portfolio Website
    📌 Project Overview

This project is a responsive personal portfolio website created to showcase my skills, projects, and contact information as a CodeAlpha Front-End Development Internship.

The portfolio is designed with a clean and attractive user interface and provides an easy way for visitors to learn about my development skills and projects.

    🚀 Features
        🏠 Home section with personal introduction
        👨‍💻 About section
        🛠️ Skills section
        📂 Projects section
        📞 Contact section
        🔗 Social media links
        📱 Responsive design for different screen sizes
        ✨ Hover effects and smooth visual interactions
        🎨 Clean and user-friendly interface 

    🛠️ Technologies Used
        HTML5 – Website structure
        CSS3 – Styling, layout and responsive design

    📂 Project Structure
        Portfolio/
                │
                ├── index.html
                ├── style.css
                └── README.md
    
    💻 Sections Included
    🏠 Home

    Introduces me as a Front-End Developer and provides a quick overview of my profile.

    👨‍💻 About

    Contains information about me and my development journey.

    🛠️ Skills

        Displays the technologies and tools I have learned, including:

        HTML
        CSS
        Git & GitHub
    
    📂 Projects

         Showcases my development projects with descriptions and links to view the projects.

    📞 Contact

        Provides contact information and links to my social profiles.

    📱 Responsive Design

        The portfolio is designed to work across different devices, including:

        💻 Desktop
        📱 Mobile
        📟 Tablet

            CSS media queries and responsive layouts are used to provide a better experience on different screen sizes.
